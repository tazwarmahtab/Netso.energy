# Framer Reference Capture Checklist

The published Framer URL could not be fetched reliably by the current browsing environment on 2026-08-11. It returned a cache miss. Therefore this checklist defines the evidence required before claiming pixel-level parity.

## Required captures

### Desktop
- full homepage from top to footer
- navigation open/closed states
- hero animation at initial load
- hero after scroll
- every hover state that matters
- calculator default and completed state
- every form state
- footer

### Mobile
- full homepage
- mobile navigation open/closed
- hero initial/scroll states
- calculator states
- forms
- footer

### Additional routes
Capture every linked page and modal.

## Audit dimensions

For every section record:
- purpose
- target audience
- message
- CTA
- layout
- typography
- spacing
- imagery/3D
- motion
- responsive behavior
- interaction states
- accessibility concern
- performance concern
- implementation recommendation

## Rule

Do not claim exact visual parity until the rendered reference has been inspected at desktop and mobile widths.
