# Netso.energy

AI-powered home energy management & optimization platform.

## Features
- **3D Storytelling Experience:** Scroll-driven narrative showcasing the journey to energy independence.
- **Energy Intelligence:** AI-driven monitoring and optimization for solar, batteries, and appliances.
- **Hardware Agnostic:** Compatible with leading solar inverters and battery systems.

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **3D Engine:** React Three Fiber (Three.js)
- **Animations:** Framer Motion + GSAP
- **Styling:** Tailwind CSS v4

## Design System
- **Colors:** Navy (#0A1628), Teal (#00D4FF), Amber (#FF8C42)
- **Typography:** Geist (Headings), Inter (Body)

## Development
```bash
pnpm install
pnpm dev
```
